# CodeCat — дизайн-спецификация

Дата: 2026-08-28
Статус: утверждена пользователем (бренд/имя: CodeCat)

## Идея

Меню-бар утилита для macOS, которая:

1. Трекает работу запущенных сессий Claude Code (CLI и desktop-приложение) в реальном времени.
2. Не даёт маку уснуть, пока агенты работают, — включая сценарии «закрыл крышку и ушёл» и «заблокировал мак в коворкинге».
3. Показывает экранного маскота-котика, который эмоциями отражает состояние работы и сигналит, когда агент ждёт человека.

Главная боль, которую решаем: агент задал вопрос или ждёт разрешения, а пользователь не заметил — время простаивает. Вторая: мак засыпает и обрывает многочасовую работу агентов.

## Платформа и стек

- Нативное приложение: Swift + SwiftUI, macOS 14+.
- Форм-фактор: меню-бар приложение (без иконки в доке), плюс оверлей-окно маскота.
- Автозапуск при логине (опционально, через SMAppService).
- Привилегированный помощник (LaunchDaemon через SMAppService) — только для режима закрытой крышки.

## Архитектура

Четыре компонента с чёткими границами:

| Компонент | Ответственность | Зависимости |
|---|---|---|
| SessionTracker | Модель всех сессий Claude Code и их состояний; публикует изменения | FSEvents, unix-сокет, PID-проверки |
| PowerManager | Управление сном: IOKit assertion + привилегированный помощник | Состояния из SessionTracker |
| Mascot Overlay | Котик-оверлей, эмоции, анимации, бейдж | Состояния из SessionTracker |
| Panel & MenuBar | Панель деталей, «пока тебя не было», настройки, меню-бар | Состояния из SessionTracker, настройки |

Поток данных однонаправленный: источники событий → SessionTracker (единый источник правды) → подписчики (PowerManager, Overlay, Panel). Компоненты не знают друг о друге, только о модели состояний.

## SessionTracker

### Источники данных (подключаемые, v1 — два)

**1. Хуки Claude Code — точные события.**

- При первом запуске приложение предлагает (с согласия пользователя) установить глобальные хуки в `~/.claude/settings.json`: `SessionStart`, `Stop`, `Notification`, `SessionEnd`.
- Каждый хук вызывает крошечный CLI-бинарник `codecat-hook` (поставляется внутри .app), который отправляет JSON-событие в unix-сокет приложения и мгновенно завершается. Если сокет недоступен (приложение не запущено) — хук молча выходит, работу Claude Code не блокирует и не замедляет.
- `Notification` — ключевое событие «агент ждёт разрешения / задал вопрос». `Stop` — «агент закончил ход».
- Установка хуков — merge в существующий settings.json без затирания чужих хуков; удаление — чистое.

**2. Наблюдение за транскриптами — детали и подстраховка.**

- FSEvents-вотчер на `~/.claude/projects/*/*.jsonl`.
- Из транскриптов берём: проект (cwd), текущую активность словами («думает», «выполняет команду», «редактирует api.ts»), время последней активности.
- Парсинг устойчивый к изменению формата: неизвестные поля/типы записей игнорируются, ошибка парсинга одной строки не роняет трекер.
- Fallback-режим: если хуки не установлены, состояние «ждёт тебя» определяется эвристикой (пауза в записи транскрипта после запроса разрешения / вопроса), с меньшей точностью.

### Модель состояний сессии

`работает` → `ждёт тебя` → `готово` | `упала`

- `работает` — есть активность в транскрипте / между Stop-событиями.
- `ждёт тебя` — пришло событие Notification (permission, вопрос) или Stop (закончил и ждёт следующего промпта — короткое время показываем как «готово»).
- `готово` — Stop без последующего промпта; через таймаут сессия считается неактивной.
- `упала` — процесс сессии умер без Stop/SessionEnd.
- Живость: периодическая проверка PID процесса `claude`; умершие сессии убираются из модели.

## PowerManager

- Пока хоть одна сессия в состоянии `работает` — держим IOKit assertion `PreventUserIdleSystemSleep`. Экран может гаснуть, мак не засыпает. Кейс «заблокировал мак в коворкинге» работает именно так: блокировка ≠ сон, процессы продолжаются.
- **Режим закрытой крышки** (тумблер, по умолчанию выключен): привилегированный помощник включает `pmset disablesleep 1`, когда есть работа, и `pmset disablesleep 0`, когда работа закончилась. Помощник устанавливается один раз с паролем администратора (SMAppService, LaunchDaemon). Кейс: «поставил задачу, закрыл ноут, ушёл с раздачей интернета с телефона — мак доработал и сам уснул».
- Grace-период: сон разрешается не сразу после последней активности, а через настраиваемую паузу (по умолчанию 2 минуты) — чтобы мак не уснул между ответом агента и следующим промптом пользователя.
- Безопасность:
  - При выходе или падении приложения помощник гарантированно сбрасывает `disablesleep` в 0 (помощник следит за живостью приложения, не наоборот).
  - Опция «не удерживать от сна при батарее ниже N%» (по умолчанию 15%).
  - Текущее power-состояние всегда видно в панели и меню-баре.

## Маскот (Mascot Overlay)

Спокойный котик (~90px), плавающее borderless-окно поверх всех окон и всех Spaces, не перехватывает фокус (non-activating panel). Перетаскивается, позиция запоминается. Можно скрыть — тогда остаётся только меню-бар.

Стиль: тёплый рисованный котик (оранжевый), спокойный характер — без прыжков и паники, всё в медленном темпе.

| Состояние | Триггер | Анимация |
|---|---|---|
| Спит | Нет активных сессий | Клубочек, медленное дыхание |
| Работает | ≥1 сессия работает | Сидит, следит глазами, хвост мерно качается; бейдж с числом активных сессий |
| Ждёт тебя | ≥1 сессия ждёт ответа | Садится столбиком, деликатно машет лапой, бейдж подсвечивается; опционально один тихий звук |
| Готово | Последняя работающая сессия закончила | Потягивается, довольное состояние, затем засыпает |
| Проблема | Сессия упала | Прижатые уши |

Агрегация: худшее состояние выигрывает (если хоть кто-то ждёт — котик зовёт). Клик по котику открывает панель деталей.

Звук: по умолчанию выключен; при включении — один тихий сигнал на переход в «ждёт тебя» и другой на «готово», без повторов.

## Панель и меню-бар

Панель (появляется у котика или из меню-бара):

- Список сессий: проект, статус, длительность, последняя активность словами.
- Блок «пока тебя не было»: после разблокировки экрана — что произошло (кто закончил, кто ждёт).
- Тумблеры: «не давать маку спать», «режим закрытой крышки», «звуки», «показывать котика».

Меню-бар: компактная иконка-статус (меняется по агрегированному состоянию) + то же меню.

## Обработка ошибок

- Хуки не установлены / удалены пользователем → трекер работает в fallback-режиме на транскриптах, панель показывает подсказку «установи хуки для точных сигналов».
- Формат JSONL изменился → защищённый парсинг, деградация до «активность есть/нет», без падений.
- Привилегированный помощник не установлен → тумблер режима крышки ведёт на установку; отказ — режим просто недоступен, остальное работает.
- Сокет-события от неизвестных сессий (например, будущие типы) → игнорируются с логом.

## Тестирование

- Unit-тесты на парсер транскриптов и машину состояний сессий — на фикстурах из реальных (анонимизированных) JSONL-файлов.
- Unit-тесты на merge/удаление хуков в settings.json.
- Логика PowerManager (когда брать/отпускать assertion, grace-период) — тестируется на мок-часах.
- Оверлей и анимации — ручная проверка; привилегированный помощник — ручной сценарий установки/сброса.

## За скобками MVP (v2+)

- Статистика: время работы агентов, число сессий, токены.
- Звуковые темы, кастомные маскоты.
- Уведомления в Notification Center как дубликат сигналов.
