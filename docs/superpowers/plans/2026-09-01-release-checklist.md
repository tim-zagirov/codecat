## Шаг 2. Подпись — главный блокер прода

Сейчас бандл подписан ad-hoc (`make app` делает `codesign --force -s -`). Отсюда
два следствия, оба видны уже сегодня:

- **Каждая переустановка меняет подпись**, поэтому macOS заново спрашивает
  разрешение на автоматизацию (переход к сессии в терминале), а выданные ранее
  разрешения обнуляются. Сбросить вручную: `tccutil reset AppleEvents com.codecat.app`.
- **На любом другом маке Gatekeeper не даст запустить** бандл без обхода
  карантина.

Что делать (нужен аккаунт Apple Developer — это может только человек):

1. Получить сертификат Developer ID Application.
2. В `Makefile` заменить `codesign --force -s -` на подпись этим сертификатом с
   `--options runtime` (hardened runtime).
3. Нотаризовать (`xcrun notarytool submit`) и прикрепить тикет (`xcrun stapler staple`).
4. Проверить на чистом маке: скачался, открылся без правого клика, разрешения
   пережили переустановку.

Если аккаунта не будет — это осознанное решение «только для себя»; тогда надо
записать в README, что установка на другой машине требует обхода карантина, а
разрешение на автоматизацию спрашивается заново после каждой переустановки.

## Шаг 3. Версия и упаковка

- Версия не менялась ни разу: `0.1.0`, build `1`. Перед сборкой прода поднять
  `CFBundleShortVersionString` и сделать `CFBundleVersion` производным от счётчика
  коммитов (`git rev-list --count HEAD`), чтобы две сборки нельзя было спутать.
- Цели `release` в `Makefile` нет — только `test`, `app`, `clean`. Добавить
  `make release`: собрать, подписать, нотаризовать, положить `.zip` или `.dmg`
  рядом с версией в имени.
- Показать версию в меню-баре (пункт «CodeCat 0.2.0») — иначе по установленному
  бандлу не понять, что именно стоит.

- **Остров** целиком: галтели у кромки, раскрытие по наведению, переход

- **Бейдж**: пусто — кот спит без числа; идёт работа — ровно столько, сколько
  агентов работает; закончил — поза без числа.
- **Анимация «закончил»**: потянулся дважды → улёгся → спит.
- **Хуки**: событий стало пять, старая установка читается как неполная —
  проверить, что пункт «Установить хуки Claude Code…» появляется и чинит.
- **Тумблер «Прятать остров, когда сессий нет»** в обе стороны.

## Шаг 5. Дыры, которые я бы закрыл до прода

**5.1. Внутрь приложения нельзя заглянуть.** Логов нет вовсе: единственный
`FileHandle.standardError` в `AppState` уходит в никуда, потому что бандл
запускают из Finder. Весь сегодняшний разбор пришлось вести внешним двойником на
той же `CodeCatCore`. Для прода нужен файл лога (события хуков, переходы
состояний, ошибки) и пункт меню «Скопировать диагностику» — он окупится в первый
же раз, когда что-то поведёт себя не так.

**5.2. У app-таргета нет ни одного теста.** Все 364 — в `CodeCatCoreTests`.
`AppState`, `IslandController`, `OverlayController`, хост-вью не покрыты ничем, а
именно там сегодня переписана модель окна и ввода. Минимум: вынести решения из
контроллера в чистые функции ядра (что сделано для геометрии — то же для
состояний меню) и покрыть их.

**5.3. Нет пути удаления.** `HooksInstaller.remove` написан и протестирован, но
**нигде не вызывается**: убрать хуки из настроек Claude Code через интерфейс
нельзя. Нужен пункт меню «Убрать хуки» и абзац в README про полное удаление
(бандл, хуки, `~/Library/Application Support/CodeCat`, режим крышки через
`scripts/uninstall-lid-mode.sh`).

**5.4. Клики во время раскрытия острова.** Окно встаёт в конечный размер сразу, а
форма догоняет пружиной ~0.3 с; в это время прямоугольник окна перехватывает
клики на ещё не закрашенной площади. Лечится hit-тестом по самой форме
(`IslandLayout.silhouettePath` уже даёт `CGPath` — `contains` по нему).

**5.5. Крылья перекрывают строку меню.** По 72 pt плюс 10 pt галтели с каждой
стороны: клики по меню приложения слева и по статус-иконкам справа в этой зоне
достаются острову. Это цена формы, но её стоит либо принять явно в README, либо
уменьшить крылья.

## Шаг 6. Эксплуатация

- Автозапуск есть (`SMAppService`, пункт «Запускать при логине») — проверить, что
  после нотаризации он продолжает работать.
- Мак без выреза / внешний монитор: остров недоступен, показывается подсказка;
  проверить, что переключение вида не оставляет пользователя без маскота.
- Несколько экранов и смена конфигурации дисплеев — пункт чек-листа 25.
- Приватность: приложение читает только `~/.claude/projects` и пишет в
  `~/Library/Application Support/CodeCat`. Наружу не уходит ничего — это стоит
  сказать в README прямым текстом.
