# CodeCat 🐈

Кот в меню-баре, который следит за сессиями Claude Code, не даёт маку уснуть,
пока агенты работают, и машет лапой, когда кому-то из них нужен ты.

*[English version](README.md)*

![Остров в вырезе: работают два агента](docs/media/island-badge.png)

## Как это работает, за 30 секунд

Claude Code шлёт хуки на пять событий сессии. CodeCat ставит обработчиком на все
пять маленький бинарник (`codecat-hook`); тот пересылает событие через unix-сокет
приложению, которое держит состояние каждой живой сессии. Транскрипты в
`~/.claude/projects` добавляют подробности — какой проект и чем агент занят прямо
сейчас («редактирует api.ts», «выполняет команду»).

Из этого состояния следуют три вещи: поза кота, IOKit power assertion, который не
даёт маку заснуть, пока хоть один агент работает, и список, по строке которого
можно кликнуть и попасть ровно в ту вкладку терминала, где сессия живёт.

Наружу не уходит ничего: сетевого кода в CodeCat нет вовсе.

## Установка

Скачай свежий `CodeCat-<версия>.dmg` из
[Releases](https://github.com/tim-zagirov/codecat/releases), открой, перетащи
`CodeCat.app` в `/Applications` и запусти. Сборка подписана и нотаризована,
поэтому открывается обычным двойным кликом — без правого клика и «Всё равно
открыть».

Дальше, из меню кота:

1. **Установить хуки Claude Code…** — без них CodeCat тоже работает, но о
   состоянии сессий узнаёт с задержкой, по транскриптам, а не по событиям.
2. По желанию — **режим закрытой крышки**: один раз попросит пароль
   администратора.

Homebrew cask запланирован, но пока его нет.

Нужен macOS 14 или новее. Apple silicon и Intel.

## Что умеет

- **Следит за всеми локальными сессиями Claude Code** — и CLI, и десктопного
  приложения — в реальном времени.
- **Показывает кота.** Он спит, когда ничего не идёт; работает, пока работают
  агенты; машет лапой, когда кто-то ждёт ответа; потягивается и укладывается,
  когда работа закончена. Восемь спрайтовых обликов на выбор.
- **Два способа его показать:** плавающий кот, которого таскаешь мышью, или
  *остров* — чёрная плашка вокруг выреза встроенного экрана, раскрывающаяся в
  меню по наведению.
- **Переход к сессии.** Клик по строке — и ты в той самой вкладке терминала, где
  эта сессия запущена.
- **Не даёт маку заснуть**, пока агенты работают, и отпускает, когда закончили.
- **Режим закрытой крышки.** Закрой макбук и уходи — агенты доработают.
- **«Пока тебя не было»** — сводка того, что случилось, пока экран был заблокирован.

## Хуки: что пишется и как это забрать обратно

**Установить хуки Claude Code…** добавляет по одной записи на событие в
`~/.claude/settings.json`:

```jsonc
{
  "hooks": {
    "SessionStart":     [{ "hooks": [{ "type": "command", "command": "/Applications/CodeCat.app/Contents/MacOS/codecat-hook" }] }],
    "UserPromptSubmit": [{ "hooks": [{ "type": "command", "command": "/Applications/CodeCat.app/Contents/MacOS/codecat-hook" }] }],
    "Stop":             [{ "hooks": [{ "type": "command", "command": "/Applications/CodeCat.app/Contents/MacOS/codecat-hook" }] }],
    "Notification":     [{ "hooks": [{ "type": "command", "command": "/Applications/CodeCat.app/Contents/MacOS/codecat-hook" }] }],
    "SessionEnd":       [{ "hooks": [{ "type": "command", "command": "/Applications/CodeCat.app/Contents/MacOS/codecat-hook" }] }]
  }
}
```

Пять событий, один бинарник, без аргументов. Все остальные ключи файла — список
разрешений, MCP-серверы, чужие хуки — сохраняются как есть, а повторная установка
ничего не дублирует.

`codecat-hook` читает событие со stdin, отправляет его в
`~/Library/Application Support/CodeCat/hook.sock` и завершается. Claude Code он не
задерживает никогда: если CodeCat не запущен, отправка не удаётся, хук пишет одну
строку в лог и выходит с кодом 0.

**Чтобы убрать:** меню кота → **Убрать хуки Claude Code…**. Удаляются только
записи с нашей командой, всё остальное остаётся нетронутым. Сделай это **до**
удаления бандла — иначе в настройках останутся пять записей, зовущих
несуществующий бинарник, на каждое событие каждой сессии.

Полное удаление:

```bash
# 1. Сначала убрать хуки из меню, затем:
sudo bash /Applications/CodeCat.app/Contents/Resources/uninstall-lid-mode.sh  # если включал режим крышки
rm -rf /Applications/CodeCat.app
rm -rf ~/Library/Application\ Support/CodeCat
```

## Режим закрытой крышки и что именно ему разрешено от root

macOS засыпает, когда закрываешь крышку, и это убивает всё, что агенты не успели
доделать. Режим закрытой крышки переключает `pmset -a disablesleep`, пока агенты
работают, и снимает флаг, когда они закончили.

`pmset -a disablesleep` требует root, поэтому первое включение запускает
`scripts/install-lid-mode.sh` под паролем администратора. Он ставит ровно две
вещи.

**1. Правило sudoers в `/etc/sudoers.d/codecat`**, только для твоего пользователя:

```
<ты> ALL=(root) NOPASSWD: /usr/bin/pmset -a disablesleep 1, /usr/bin/pmset -a disablesleep 0
```

Две буквальные командные строки. Не `pmset` вообще и не маска — ровно те два
набора аргументов, которые запускает CodeCat, и ничего больше. Файл проверяется
`visudo -cf` до установки.

**2. Демон `com.codecat.sleepreset`**, который раз в 60 секунд спрашивает:
CodeCat запущен? Если да — не делает ничего вообще. Если нет, а `SleepDisabled`
всё ещё 1 — снимает флаг. Это страховка на случай падения или Force Quit при
выставленном флаге: без неё флаг дожил бы до перезагрузки. Демон проверяет перед
тем, как писать, поэтому у простаивающего мака никто не переписывает настройки
энергосбережения от root раз в минуту вечно.

`scripts/uninstall-lid-mode.sh` убирает обе вещи.

## Приватность

- **Никакой сети.** CodeCat не делает исходящих соединений. Ни аналитики, ни
  телеметрии, ни отчётов о падениях, ни проверки обновлений.
- **Читает** `~/.claude/projects` (транскрипты) и `~/.claude/settings.json`
  (только чтобы добавить или убрать свои записи хуков).
- **Пишет** только в `~/Library/Application Support/CodeCat` — сокет, кэш
  маршрутов и лог.
- Лог `~/Library/Application Support/CodeCat/codecat.log` ротируется на 1 МБ и
  занимает не больше двух файлов. Он остаётся на диске, и читаешь его только ты.

## Сборка из исходников

```bash
git clone https://github.com/tim-zagirov/codecat.git
cd codecat
swift test        # 400 тестов
make app          # dist/CodeCat.app, подпись ad-hoc — для работы на своей машине
```

`make app` достаточно, пока приложение не покидает эту машину. Для раздачи нужны
сертификат Developer ID и профиль нотаризации — см. [docs/release.md](docs/release.md).

Один облик («Серебристый») в репозитории не лежит: автор разрешает использовать
спрайты, но не раздавать сами файлы. `make bundle` запускает
`scripts/fetch-optional-assets.sh`, который скачивает лист с itch.io. Если не
получилось — нет сети, или itch.io поменял процедуру, — сборка всё равно проходит,
а облик просто не появляется. См. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

### Что проверено, а что нет

Автоматически, на каждом `swift test`: весь `CodeCatCore` — разбор хуков и
транскриптов, агрегатный статус сессий, power assertion, away-log, правка
`settings.json`, обход дерева процессов и выбор маршрута перехода, реестр
спрайтов против настоящих PNG и оба каталога строк против мест вызова. Сборка
дополнительно проверяет, что в собранный `.app` действительно попали облики и
локализации.

Руками, потому что у `LSUIElement`-приложения нет окна, которое нашли бы
инструменты управления экраном: всё из
[docs/verification-checklist.md](docs/verification-checklist.md). Режим закрытой
крышки не запускался сквозным образом ни разу — он требует пароля
администратора и потому не выполнялся при разработке.
